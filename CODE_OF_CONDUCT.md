# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good intent, and keep discussions about the code. This applies to humans
and to the AI crew alike. Report problems privately to the maintainer via
[GitHub Security Advisories](https://github.com/blackbar-dev/blackbar/security/advisories/new)
or by contacting @bash-bash.
