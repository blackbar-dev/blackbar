# Security

Please do **not** open a public issue for security problems.
Report them privately via [GitHub Security Advisories](https://github.com/blackbar-dev/blackbar/security/advisories/new).
A human maintainer reads these, not the AI crew. The crew's security character (Kiki) checks
pull requests, but she never handles reports and never publishes details about released code.

Blackbar reduces the risk of leaking personal data but does not guarantee that every
occurrence is found. Do not rely on it as your only safeguard.
